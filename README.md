## Controls
- **Tap** a plush part to fill it. **Drag** empty space to spin the turntable. Brush mode: drag on the plush.
- Left strip: current tool, fill / brush, size, mirror, undo, 💡 hint (shows real colors), 🌙 lights, 🎲 surprise me.
- Top: ▶ start, ⏸ pause, ⏹ back to title, 🎵 music, 🔔 sounds, ✓ done (dance party).
- Work saves automatically on this device.

Pure static site (Three.js r161, no build step, no backend).
